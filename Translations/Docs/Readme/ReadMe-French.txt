WINMERGE

WinMerge est un logiciel libre de comparaison et de fusion pour Windows.
WinMerge peut comparer aussi bien des dossiers que des fichiers, en présentant
les différences sous un format textuel visuel facile à comprendre et à manipuler.
WinMerge peut être utilisé comme outil externe de comparaison/fusion ou 
comme application autonome.

WinMerge possède de nombreuses fonctionnalités utiles pour rendre la comparaison,
la synchronisation et la fusion aussi simples et pratiques que possible. Plusieurs
langages de programmation et autres formats de fichiers bénéficient de la coloration
syntaxique.

La dernière version de WinMerge et les informations associées sont disponibles sur :
https://winmerge.org/

Démarrage rapide
================
Pour apprendre à effectuer des opérations de base après l'installation de WinMerge,
cliquez sur Aide > Aide de WinMerge et accédez à la rubrique Démarrage rapide.
Ou consultez la version Web sur :
https://manual.winmerge.org/Quick_start.html

Aide de WinMerge
================
L'aide de WinMerge est installée localement sous la forme d'un fichier d'aide HTML
de Microsoft, WinMerge.chm, lorsque vous installez WinMerge. Pour ouvrir l'aide,
cliquez sur Aide > Aide de WinMerge ou appuyez sur F1 dans la fenêtre WinMerge.
En ligne de commande, lancez l'exécutable WinMerge avec l'option d'aide /?.

Vous pouvez également consulter la version HTML de l'aide de WinMerge sur :
https://manual.winmerge.org/

Support de WinMerge
===================
Des questions ou des suggestions à propos de WinMerge ? Un bon point de départ
est le forum communautaire de WinMerge sur https://github.com/WinMerge/winmerge/discussions.
Les développeurs lisent et répondent fréquemment aux questions sur le forum.

Bogues et demandes de fonctionnalités
=====================================
Si un problème n'est pas résolu sur les forums de WinMerge, consultez les outils de suivi
du projet : rendez-vous sur https://github.com/WinMerge/winmerge/issues, où vous pouvez
parcourir ou créer des problèmes.

Si vous soumettez un bogue, veuillez inclure le numéro de version de WinMerge
dans votre rapport. Vous pouvez générer un journal de configuration en cliquant
sur Aide > Configuration. Veuillez joindre le journal de configuration
à votre rapport de bogue ; il contient beaucoup d'informations utiles
pour les développeurs.
